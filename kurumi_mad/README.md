## 視覺手法

- **視窗 UI**：場面寫真放進仿官網風格的視窗，搭配即時 K 線視窗、入金／錯誤對話框（強制ロスカット時錯誤視窗每拍疊一個）。視窗按鈕、貨幣符號、星星、對話泡泡、K 線底圖都是官網的裝飾素材。
- **角色去背貼紙**：官方立繪加白色外框，疊在斜切色塊與網點上。
- **透視**：里程表的照片卡以 3D 翻牌入場；地面是往鏡頭衝的透視格線。
- **轉場與衝擊**：切換時的橫向動態模糊甩入、入鏡的三段階梯變焦、鏡頭中段的跳切拉近、放射模糊、衝擊波圓環、譜面閃點上的兩格負片。
- **字體**：敘事與介面用 Chiron GoRound TC（圓體，中日文字形齊全），戲劇性標題用 Shippori Mincho B1，喊話用 Mochiy Pop One，年份與大數字用 Unbounded。

## 重新生成

```bash
python3 fetch_assets.py
```

把 `audio.mp3`、`map.osu` 和字型放進 `assets/`（見 `fetch_assets.py` 開頭說明），然後：

```bash
pip install numpy pillow opencv-python-headless fonttools
```

```bash
python3 render.py all kurumi_mad.mp4
```

單格預覽：

```bash
python3 render.py still 185.0 preview.png
```

環境變數：`MAD_ASSETS`（素材目錄）、`MAD_FPS`（預設 60）、`MAD_JOBS`（平行程序數）。

素材來源、授權與片中數字的依據見 [SOURCES.md](SOURCES.md)。
